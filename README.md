# Todo List

A simple Todo List application built with HTML, CSS, and Vanilla JavaScript.

The project allows users to create, manage, search, and filter tasks. All data is stored in Local Storage, so tasks remain available after refreshing the page.

## Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✔️ Mark tasks as completed
* 🔍 Search tasks by name
* 📂 Filter tasks:

  * All
  * Complete
  * Incomplete
* 🌙 Light/Dark theme
* 💾 Automatic saving with Local Storage
* 📱 Responsive layout

## Technologies

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* Local Storage API
